# 🔊 Sounds Folder

Put your downloaded sound files here!

## Supported Formats
- .mp3 (recommended)
- .wav
- .ogg

## Example Files
- breathing-in.mp3
- breathing-out.mp3
- calm-music.mp3
- success.mp3
- error.mp3

## How to Use
In your game code:
```javascript
const sound = new Audio('/sounds/breathing-in.mp3');
sound.play();
```
